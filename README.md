# Winter Walks

Укажи своё место (GPS, поиск или точка на карте) и радиус — приложение покажет парки, набережные, тропы, смотровые площадки, достопримечательности и другие фото-места рядом, с фото, расстоянием и маршрутом. Вкладка «Новости» — новости твоего района, города или области за неделю.

Новости: основной источник — Google Новости, запасной — открытый API GDELT (если Google не ответит).

## Установка

Приложение семейства **Winter Hub** (Android + Windows). Удобнее всего ставить и обновлять через Winter Hub, либо скачать файл из раздела **Releases**: `Winter-Walks.apk` для телефона, `Winter-Walks-Setup.exe` для ПК.

## Как устроено

Flutter (Dart). lib/places.dart — места (OpenStreetMap, Википедия), lib/news.dart — новости, lib/geo.dart — геолокация.

Сборку делает GitHub Actions при каждом изменении в `main`: анализ кода, тесты (`test/`), сборка APK и установщика для Windows, подпись постоянным ключом (общие скрипты в `winter-hub/ci`) и публикация в Releases.
